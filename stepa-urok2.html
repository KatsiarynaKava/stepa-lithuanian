📣 Šauksmininkas — Звательная форма
Когда обращаешься к человеку по имени — окончание меняется! У женских имён обычно ничего не меняется.
ОкончаниеСтановитсяПример
-as → -ai Tomas → Tomai
-is → -i Ignatis → Ignati
-ys → -y Balys → Baly
-us → -au Paulius → Pauliau
-a → -a Lina → Lina ✅
-ė → -e Eglė → Egle
-ija → -ija Viktorija → Viktorija ✅
💡 ponas → pone при обращении! Laba diena, pone Jonai!
